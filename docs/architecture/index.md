# Social Hashtags & Mentions Architecture

For contributors, and for developers who need to know how Social Hashtags & Mentions works inside: where its code lives and how it loads, its functions and hooks, and what it stores. For what other plugins and themes should use, see the [Developer Reference](../developer-reference.html). Coding standards for the whole suite are in HyperTaxonomy's [Contributing guide](https://hypertaxonomy.org/hypertaxonomy/architecture/contributing.html).

The Function Reference and Hook Reference are generated from the code and its docblocks.

- **[File Structure & Loading](file-structure.html)** — the directory layout and the order files load in.
- **[Function Reference](function-reference.html)** — every function and public method, by file.
- **[Hook Reference](hook-reference.html)** — the callbacks Social Hashtags & Mentions registers, and the hooks it fires.
- **[Data Storage](data-storage.html)** — its taxonomies, term meta, options and transients.
